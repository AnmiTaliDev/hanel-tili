# Orthography

## Writing Systems

- Cyrillic serves as the primary script for the language.
- Latin serves as a secondary romanization scheme.
- A proprietary script is planned for future implementation.

## Base Cyrillic Alphabet

The primary alphabet contains 27 characters:

А, Ә, Б, В, Г, Д, Е, Ж, З, И, Й, К, Л, М, Н, Ң, О, Ө, П, Р, С, Т, У, Ү, Х, Ш, Ы

### Excluded Letters

The following characters are omitted from the standard inventory:

Ц, Ч, Щ, Ъ, Ь, Э, Ю, Я

### Representation of Iotated Vowels

Fused iotated letters are not utilized. Pre-iotated sequences are represented analytically using digraphs with initial <й>:

- <йа> instead of <я>
- <йе> instead of initial <е> where distinct /je/ is intended
- <йу> instead of <ю>
